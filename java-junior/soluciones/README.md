Puedes compilar todas las clases con Java 17 o posterior desde esta carpeta.

```sh
javac -encoding UTF-8 *.java
java ClasificadorAnchoDeBanda
```

Escribe un entero en Mbps cuando el clasificador espere la entrada. Las clases que definen métodos sin `main` se pueden llamar desde un programa de prueba.

En el ejercicio 06, «Telecomunicaciones» tiene 9 vocales y 9 consonantes.
